## 四、约定

1. 脚本内一律写死数据路径与随机种子，不依赖交互输入；
2. 图注不写编号，编号由模板生成；
3. 正式定稿前执行一次全量重跑，把输出图的修改时间与本次提交对应起来；
4. 若某个数字在正文出现但无脚本可复现，视为未完成，不得进入终稿；
5. 图的输出目录全稿唯一，为 `格式排版/Pictures/`，正文中的 `Pictures/...` 即指此目录。`新稿/` 下不得再建 `Pictures/`：pandoc 解析相对路径时先查 md 所在目录，一旦那里存在同名目录，就会静默命中旧副本而丢图（2026-11-19 已删除该副本）。编译时在 `格式排版` 目录下执行，图片按当前工作目录解析；
6. 每轮改图后跑 `cd 格式排版 && python _check_figs.py`，检查文件存在性、PNG 合法性、像素宽、章内编号连续、标签闭合、图源清单登记六项。
