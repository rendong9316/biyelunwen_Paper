# 论文工作目录

唯一维护的论文正文是 [论文全文.md](论文全文.md)。后续直接编辑其中的对应章节，不再拆成七份文件，也不再生成根目录完整稿。历史正文通过 Git 查阅。

| 内容 | 位置 |
| --- | --- |
| 完整论文 | [论文全文.md](论文全文.md) |
| 正式图片 | [Pictures/](Pictures/) |
| 图片来源与复现索引 | [图源清单.md](图源清单.md) |
| 绘图、图片提取与溯源脚本 | [绘图溯源/](绘图溯源/) |
| 正文和图片检查 | [校验工具/](校验工具/) |
| 参考文献、Markdown 格式资料 | [写作资料/](写作资料/) |
| 历史修订说明 | [修订记录/](修订记录/) |

正文图片路径统一写为 `Pictures/文件名.png`，相对于本目录解析。框图继续保持白底、黑字、黑色矩形框与箭头。

在本目录执行检查：

```powershell
python 校验工具/_check_merged.py
python 校验工具/_check_figs.py
```

`_check_merged.py` 沿用历史文件名，当前只检查完整正文，不执行合并。原始 MATLAB 工程与实验数据仍在相邻的 `文稿撰写` 目录，不复制到论文目录；绘图脚本按原始数据位置读取。

每轮修改前检查 Git 状态，完成后运行相应检查并创建本地提交。根目录 `AGENTS.md` 是持久协作说明入口。
