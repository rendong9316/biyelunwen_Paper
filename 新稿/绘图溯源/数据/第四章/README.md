# 第四章单站滤波对照的复现与口径

MATLAB R2023a（9.14.0.2206163）实际调用原工程 `ukf_jichu.m`、`ukf_imm.m`、`run_oracle_tracker_sequence.m` 及其初始化、确认和航迹管理函数。本轮没有修改研究工程源码。源代码哈希与依赖见 `provenance.json`，导出入口在上两级的 `export_ch4_filtering.m`。

## 实验条件

使用覆盖互补配置的R1站、两种滤波方法（CV-UKF / IMM-UKF）、三个固定轨迹、两个实际命中概率（0.6 / 0.9）、种子41001—41050，共600个方法结果。基准检测概率仍是0.6，0.9仅为独立实验注入，滤波器内部检测先验保持0.6。轨迹种类与命中概率之间重复使用同一随机种子以形成配对，不将600行当作600个独立交通场景。

群距离/方位/多普勒噪声为10000m/0.35度/0.5m/s。传播模型和滤波模型均固定300km虚高、零偏置，以隔离配准影响；生成侧直接调用现有UKF观测函数。IMM转弯率为±0.05和±0.2度/秒，过程加速度谱密度为0.02m²/s³，未开启自适应或Q调度。采样间隔30秒；滑窗3/7确认、连续8帧漏检终止，关闭依赖参考结束时刻的终止。Oracle身份目录只为现有站内理想关联与起始器分配槽位，不注入参考位置或速度作为初值。

纯仿真：初始110°E、30.1°N，速度230m/s，0—1800秒。直线一直向北，转弯在600—1200秒以0.15度/秒左转，1秒球面正算后每30秒采样，共61点。ADS-B：第三章选段 `T06677` 共77点，源数据哈希和选段规则仍见相邻第三章目录；生成侧参考速度采用位置的数值差分。所有点均验证在R1视场内。

## 文件

`monte_carlo.csv` 为逐次方法指标；`summary.csv` 为按场景、命中概率、方法汇总；`paired_differences.csv` 为IMM减CV的全输出帧位置RMSE差值及配对自助抽样区间（以种子为单位，10000次，抽样种子20261124）。

`*_reference.csv` 为参考位置与速度及转弯标记。`*_demo.csv` 为预先固定种子41001、命中概率0.6的图示数据，含参考位置、逐点定位、滤波状态位置、位置/二维速度误差、NIS、NEES、航迹ID、更新与命中标记。NaN表示未起始或未输出、无量测或未执行更新，不当作零。图片没有进行事后平滑，不连接不同航迹ID的空缺段。

直接定位与滤波比较：两种滤波器均有输出且有命中的共同帧。连续估计比较：两种滤波器均有输出的共同帧，包括预测帧。先按每个种子计算RMSE，再计算跨种子的均值与样本标准差。输出比例单独以整个参考序列作分母；没有用误差阈值剔除种子。初始化前的帧不纳入误差，但计入未输出比例。二维速度误差为东北速度向量之差的模，不是速度大小之差。NIS只统计更新帧，NEES只统计有效可逆协方差帧；名义区间覆盖率按各次运行先计算再平均。

全部300组条件均起始成功。低命中条件下直线和纯仿真转弯各1次、ADS-B共3次重起；两方法生命周期相同。ADS-B条件下滤波误差未低于逐点定位，正文已保留此限制，不能将图片描述为普遍精度提升。

`map_background.geojson` 来自 Natural Earth 公共领域（Public Domain）的1:10m省级边界线和河流线，局部截取104—114°E、27—37°N；下载地址与原始shp哈希写在文件 `sources`。不含国界、不是导航或测绘成果。图片中文字以宋体显示，地图线条不参加计算。城市为近似位置标注，仅用于读图定位。

## 复现

从 `格式排版` 根目录执行：

```powershell
& 'C:\Program Files\MATLAB\R2023a\bin\matlab.exe' -batch "addpath('新稿/绘图溯源'); export_ch4_filtering(50)"
python 新稿/绘图溯源/prepare_ch4_map.py
python 新稿/绘图溯源/_fig_ch4_filtering.py
python 新稿/校验工具/_check_ch4.py
python 新稿/校验工具/_check_merged.py
python 新稿/校验工具/_check_figs.py
```

已保存局部地理数据，日常绘图不需要重新下载。`_fig_ch4.py` 为兼容入口，调用新脚本；旧逐目标尾部图留在图片历史目录，当前正文不再以其证明重尾分布或匀速滤波极限。
